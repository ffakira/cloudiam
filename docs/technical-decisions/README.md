# Technical Decisions

Use this folder for architecture and implementation decisions.

Decisions should be grouped by task or initiative:

```text
technical-decisions/
  TASK-000001-short-name/
    README.md
    001-contract.md
    002-follow-up-decision.md
```

Each decision should explain:

- context
- options considered
- decision
- consequences
- date created

Suggested filename format:

```text
YYYY-MM-DD-short-title.md
```
